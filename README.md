# 📊 Dashboard de Vendas no Excel

## 📌 Sobre o Projeto

Este projeto foi desenvolvido como parte de um desafio da **DIO**, com o objetivo de criar um dashboard de vendas utilizando o **Microsoft Excel**.

A proposta foi transformar dados brutos de vendas em informações visuais, facilitando a análise dos resultados e permitindo uma melhor compreensão do desempenho das vendas.

## 🎯 Objetivo

Criar um dashboard interativo e organizado capaz de apresentar informações relevantes sobre as vendas, utilizando gráficos, indicadores e recursos de análise de dados do Excel.

## 🛠️ Tecnologias e Ferramentas

- Microsoft Excel
- Tabelas e organização de dados
- Gráficos
- Dashboard
- Análise e visualização de dados

## 📊 Desenvolvimento

Durante o desenvolvimento do projeto, os dados foram organizados e tratados no Excel para posteriormente serem utilizados na construção do dashboard.

Foram criadas visualizações com o objetivo de facilitar a interpretação dos dados e destacar os principais indicadores relacionados às vendas.

## 💡 Resultado

O resultado foi um **dashboard de vendas no Excel**, permitindo visualizar os dados de forma mais clara, organizada e intuitiva.

O projeto demonstra como ferramentas de análise e visualização de dados podem transformar informações brutas em insights úteis para auxiliar na tomada de decisões.

- `README.md` — documentação do projeto.
